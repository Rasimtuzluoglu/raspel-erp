## Faz 2 — Passkey

- V176 `sistem.passkey`; WebAuthn4J 0.29.7; `PasskeyService` + `PasskeyController`.
- Uçlar: kayıt seçenekleri/kayıt/liste/silme, giriş seçenekleri/giriş, ADMIN sıfırlama.
- Challenge Redis (`passkey:reg:*`, `passkey:auth:*`), 5/2 dk TTL; parola onayı; signCount kontrolü.

### Frontend
1. `api/modules/sistem.js`: `passkeyAPI` (kayitSecenekleri, kaydet, listele, sil, girisSecenekleri, giris).

3. `GirisFormKarti.vue`: “Passkey ile giriş” butonu (destek varsa); seçenekleri al → `navigator.credentials.get` → giriş → şirket seçimi/otomatik.
4. `HesapAyarlari.vue` Güvenlik sekmesi: passkey listesi, “Passkey ekle” (parola + etiket), sil; destek yoksa açıklama.
5. `KullaniciDetay`/Kullanıcılar ekranı: ADMIN “Passkey’leri sıfırla”.
6. i18n `passkey.*`; tr/en simetrik.
7. Testler: destek yoksa gizli; başarı/iptal; listeleme/silme; şirket seçimi; API mock.

- Cypress: passkey butonu (destek varsa) veya gizli; mock API ile akış.

## Faz 3 — QR oturum onayı

### Backend (tamamlandı)
- `QrOturumService` + `QrOturumController`; Redis `qr:oturum:*`, `qr:giris:*`, 120 sn, tek kullanım.
- Uçlar: oluştur, durum, PNG, onayla/reddet, `giris-qr-tamamla`.
- Yalnız 2FA açık ve henüz doğrulanmamış girişler; onaylayan = giriş sahibi.

### Frontend
1. `api/modules/sistem.js`: `qrOturumAPI`.
2. `GirisFormKarti.vue` 2FA adımı: “QR ile onayla” → panel; `qrUrl` görseli (`/gorsel`), geri sayım, poll (2 sn), iptal; “Kodu elle gir” fallback.
3. `views/QrOnay.vue` + router `/qr-onay/:token` (`requiresAuth: true`): tarayıcı/IP özeti, şirket, Onayla/Reddet; başarı/hata durumları.
4. `authStore`: `qrOturumBaslat`, `qrOturumDurum`, `qrOturumOnayla`, `qrOturumReddet`, `girisQrTamamla`.
5. i18n `qrOnay.*`; tr/en simetrik.
6. Testler: panel aç/kapa, poll ONAYLANDI/REDDEDILDI/SÜRE, mobil onay sayfası, tek kullanım.
7. Cypress: API intercept ile QR panel; 390px taşma yok.

### Kabul
- Tüm kapılar + Docker + canlı E2E (masaüstü QR oluştur, mobil onay, giriş).
